# Пример списка для Solana: один шаблон на строку.
# слово       — адрес начинается с него
# ..слово     — адрес заканчивается на него
# нач..кон    — и то и другое; ? — любой символ; [aA] — любой из перечисленных
# В base58 нет символов 0 O I l (с флагом -l вместо них берутся похожие).
moon
pump
bonk
hodl
wagmi
..pump
..moon
Sun..Sun
